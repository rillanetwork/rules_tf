- Note, so it is not investigated a third time: tflint's `checksums.txt` is not going to be verified. It is signed with cosign keyless, and cosign is the only practical verifier - every published binary is 130-150 MB, with no slim build. Verification also cannot be done offline: a Fulcio certificate is valid for ten minutes, so establishing the signing time needs an online Rekor lookup, and `--insecure-ignore-tlog` refuses with "expected a signed timestamp to verify an expired certificate". tflint publishes no sigstore bundle that would carry that timestamp, as of v0.64.0. The check itself does work - v0.53.0 verifies against a pinned identity and OIDC issuer, and a wrong identity, a wrong version, a wrong issuer and a tampered document each fail - but 140 MB plus a hard build-time dependency on rekor.sigstore.dev and the sigstore TUF root is not a proportionate price for checking a 712-byte document. Revisit if tflint starts publishing `.sigstore.json` bundles, which would remove the Rekor lookup.
